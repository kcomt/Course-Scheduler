# Course Scheduler

A small Python/Tkinter application that builds course schedules with a genetic algorithm.

## Requirements

- Python 3
- Tkinter (usually included with Python)

## Run

From the project directory, run:

```bash
python interface.py
```

Use the GUI to add courses, review or delete them, and generate schedules for each cycle.

## Files

- `interface.py` - Tkinter user interface
- `main.py` - genetic algorithm and schedule generation
- `courseClasses.py` - course and population data structures
